### ECT 
- Aws is a public cloud service provider whose provides infrastructure as a service.
## Elasticity
- Increasing and decreasing the number of servers based on the workload is called elasticity.
- How to achieve in AWS  :
	- we can achieve by auto scaling
	- What is Auto-Scaling :
		- Scale out : Increasing server(Adding)
		- Scale In : Decreasing server(Removing)
- Elasticity also called Horizontal Scaling.
## Scalability
- Scale UP and Scale DOWN
## Hi Availability
- The period of the time  the service is available to the customer is called High Availability.
- The period of the time the service is NOT available to the customer is called down time.
## Round Robin Method :
- If the servers are 1,2,3 and request will goes like 1,2,3 only. This method is called round robin method.
- How Load Balancer will check one server is down : 
	- By health check load balancer will check in every 30 secs interval(customizable).
- Load balancer is monitoring health of application.
## Redundancy
- Keeping same application in on multiple server is called redundancy.
## Monitoring 
- Load balancer will check is application is reachable or not
## Fail Over :
- If one server goes down, available next server will takes the requests is called fail over.
## Auto Scaling : (Auto-Scaling Groups)
- If all server goes down then we can configure auto scaling
- If you want to achieve zero down time auto scaling will come into picture also called FAULT TOLERANCE

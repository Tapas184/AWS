## Regions and Availability Zones(AZ)

- Regions : Geo-graphical area
	- This is a place where AWS has it's infrastructure.
	-  A region has multiple data centers.
	-  Mumbai region code : ap-south-1
- Availability Zone(AZ) : Simple a data center
	- Instances are placed in AZ's
	- Mumbai region code
	- AZ : ap-south-1a
		- ap-south-1b
		- ap-south-1c
- Regions and availability completely managed by AWS
- AZ inside in region
- AZ can communicate each other by default. AZ network  are interconnect with each other.
- Best practice is to  spread / Distribute the EC2 instance  across AZ's.
- Very very less chance  that AZ goes down.
- One AZ is a group of data center.
- Instance  across the AZ's shares the data. because those are inter connected with reach other.
- By default 2 regions are not able to connected each other
	- Regions don't communicate with each other by default. But if required we can set-up.

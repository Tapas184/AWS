- Tags are key value pair
- ARN (used in policy)
- Tags are used for identification purpose
- Tags are not for IAM  specific, it's for entire AWS services
- ARN's are auto-generated by AWS, where  as tags are provided by customer.
- Example : 
	- Key : Name
	- Value : Webserver
- Tags are used for automation purpose
- Tags are used for cost optimization purpose
- Max we can give 50 Tags per resource.
- Tags are important but tags are optional
- Rotate the KEYS based on your company policy

- Ec2 is a web service from AWS that can be resize able compute services in the cloud.
- **Resizable** 
	- Scale out and Scale In (Elasticity)
	- Scale up and Scale down (Scalability)
- 750 Hours are free per month
- AWS charging per hour even if user used 1 minutes or 60 minutes.
- For that AWS offering pricing models
	- **On demand instances** 
		- It has a fixed price (Pay for what you have used / pay per hour)
		- No commitment
		- No Upfront payment(Advanced)
		- No Predictable Usage
	- **Reserved Instances**
		- Long term commitment (1 to 3 years)
		- Upfront payment (Advance Payment)(Full / Partial)
		- 72 to 75% discount on hourly price
		- **Standard RI**
			- 75% discount
		- **Convertible RI**
			- To change the capacity of the instance anytime
		- Scheduled RI
			- Reverse it for short tern like fraction of a day, week or a month.
	- **SPOT Instances**  (Huge capacity in cheaper price)
		- Bidding
		- Auctioning
		- Huge capacity for cheaper price
		- 90% discount
	- **Dedicated HOST**
		- If you need a physical machine with VM's for this model
	- **Savings Plans**
		- Same as Reserved Instances(RI) but it has different strategy.
### EC2 Families / Instance Type

- **General Instances** (For General Purpose)
- **Memory Instances** (If you requires more memory)
- **CPU Instances** (More CPU's)
- **Storage Instances** (For more storage)
- **GPU Instances**  (For heavy machines, Graphics ETC)
#### How do you achieve scalability in AWS ?
- **Ans** - Changing the  instance type. Any time we can do the scale up and scale down. No data loss because data is stored in volumes.
	- While running the Ec2 instance for changing the instance type we need to stop the Ec2 instance.
	- We need to have down time if we have high availability no need to have downtime.
	- If you change the instance type, data is not lost because data is stored in EBS volumes.
**Burstable Performance Instances** (Billable)
- EC2 instance will enter into the burstable mode and it give high performance for limited period of time only.
- CPU credits depends upon the type of instances.
- Only t2 and t3 types support burstable instances.

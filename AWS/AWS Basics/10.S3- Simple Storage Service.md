## **EBS-Elastic Block Storage**
- **Hard Disk = EBS Volume**
- Default Volume : 30GB for Win
- Default Volume : 8 or 10 GB for Linux
- Volume can be attached and Volumes can be detached
- **EBS is a Block Based Storage**
- Default volume called root volume.
- Rest of root volume called additional Volume
- We can attached multiple volume to the EC2 Instance
- Root volume always contains OS(Linux, Windows)
- EC2 supports only server OS not client OS
- Maxi Size of the EBS Volume is 16TB
- Volumes Can be pre-provisioned like 50GB,100GB. max 16TB
- You cannot attach a single volume to multiple EC2 instance at the same time.
- Volume can increase on fly(No Need to stop the EC2 Instance)
- Volume size cannot be decrease if you want , you have to delete and recreate again
- Mount(Attached)
- Un-Mount(Detached)
- Root volume always have device name 
	- (For Root Volume Win/linux- /dev/sda1)
	- For Additional Volume   Win/linux- /dev/sdb,sde,sdf etc
	- For Root Volume Ubuntu - /dev/xvda
	- For Additional Volume for Ubuntu - xvdf,xvdg,xvdh etc
- We can't delete the volume while it is attached. 1st detached it then delete it.
- EC2 instance has Availability Zone, Volume also has Availability Zone
- EC2 instance and volume should be in the same availability zone
- But we can transfer the data with other availability zone because they internally connected.

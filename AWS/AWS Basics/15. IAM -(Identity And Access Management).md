- This is used for security purpose
- With IAM you can control entire AWS centrally
- For IAM users we can any time attach and detach policies
- This service is global
- Using IAM user only we can login to the AWS console
- 2 ways IAM user have the access to login
	- Console(IAM user/password)(GUI)
	- Programmatical(KEYS)
- Keys are specific, individual users have their own keys.
- Once key's are lost it lost we can't get same one again, we can re generate it n number of times.
- Maximum set of key we can create 2 only. If you want to create new one you have to delete one key from that set and generate new one.

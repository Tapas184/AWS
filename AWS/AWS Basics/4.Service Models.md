###### Deployment Models :
-  Public Cloud : The provider service which are accessed by everyone like AWS, Azure and GCP.
- Private Cloud : The provider service which are accessed with in the organization like oracle.
- Hybrid Cloud : The combination of public and private  cloud.
###### Service Models :
- Infrastructure as a Service : (**IAAS**)
- Platform as a Service : (**PAAS**)
- Software as a Service : (**SAAS**)
